# Cross-pathogen PAIS molecular signatures: shared attractor vs trigger-specific (t001)

## Focus

Does cross-pathogen *molecular* evidence support `hypothesis:0001` (PAIS are a shared
dysregulated attractor — genuine **biological** convergence across triggers) over the
trigger-specific rival (convergence is only **symptomatic**; distinct mechanisms reach a
finite repertoire of organ-system failures)? This is the decisive test named in
`question:0001`. Evidence base = the project corpus + the 2026-06-20 cross-pathogen
signature search (`doc/searches/2026-06-20-cross-pathogen-pais-signatures.md`).

## Current Position

**`convergent domains, unproven shared molecules`.** Convergence is robust at the level
of biological *domains* (immune activation, T-cell exhaustion, metabolic/mitochondrial)
but the evidence that would *prove* a shared, PAIS-specific molecular signature is
overwhelmingly **assembled from separate single-trigger studies**, not generated by
head-to-head designs. **The decisive test — harmonized multi-omics across ≥3
fatigue-phenotype triggers with full-recovery controls — does not yet exist.** So h0001 is
neither confirmed nor refuted by molecular data; it remains a domain-level regularity
awaiting a molecule-level test. This is consistent with the cautions already standing in
q0001 and h0001's *Current Uncertainty*, now sharpened by an explicit provenance audit.

### The provenance problem (the load-bearing point)

The matrix looks convergent, but almost every "supported" cell is single-trigger. The
**head-to-head** cells — the only ones that can adjudicate shared-vs-specific — are sparse
and **split in direction**:

- **Galbraith2011** (Dubbo: EBV / Ross River virus / Q-fever post-infective fatigue) —
  *partial* shared peripheral-blood transcripts across three triggers → **supports** shared
  biology. This is the single closest existing test of h0001 and should be read in full.
- **Raijmakers2021** (TSPO PET in ME/CFS *and* QFS) — a shared **negative**: no
  neuroinflammation in either. A shared absence is consistent with convergence but does not
  *demonstrate* a shared positive mechanism — weak/ambiguous for h0001.
- **Patterson2024** (ML cytokine hubs) — **separates** long COVID from chronic Lyme →
  **disputes** a shared molecular signature (caveat: ML overfitting risk, needs critical read).
- **Within-trigger heterogeneity** (Cruz2025, Peppercorn2023 direction-discordances) shows
  even *one* trigger is non-unitary — raising the bar for any cross-trigger claim.

### Coverage gaps that bound testability

`hypothesis:0001` names post-dengue and post-Q-fever among its triggers, but **post-dengue
omics are essentially absent** (only fatigue epidemiology — Conde2026) and **QFS molecular
data exist only inside Galbraith2011 + the negative Raijmakers2021**. Post-SARS(2003) is
also a molecular blank. So for *two-to-three of h0001's own named triggers the decisive
data do not exist* — h0001 is currently untestable at molecule level across its full claimed
breadth, independent of which way the LC/ME/CFS evidence points.

## Evidence Needed

- **Decisive (still absent):** one harmonized, controlled multi-omics study across ≥3
  triggers (SARS-CoV-2, Borrelia, dengue/EBV) with **full-recovery controls**, compared at
  **pathway level** not analyte level. This answers q0001 directly; nothing else does.
- **Cheapest real movement now:** read **Galbraith2011** in full (and check for reusable
  GEO data) — the nearest existing head-to-head transcriptomic test.
- **Gap-closing search:** targeted hunt for post-dengue and QFS omics; if empty, record it
  as a *structural* evidence gap limiting h0001's testability (not as evidence against).
- **Corpus-wide:** an axis×trigger **provenance overlay** (head-to-head vs assembled) so the
  shared-attractor claim is never read off a matrix of single-trigger studies again.

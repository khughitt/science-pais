# Proposition: A shared analyte signature is not required for the shared immune-state displacement hypothesis (degeneracy / evidence-bar)

## Claim

Because the object shared across PAIS is a **persistent immune-state displacement** that
may be **degenerately realized** — many molecular configurations producing one persistent
macro-state — `hypothesis:0001` does **not** entail that every trigger/subtype shares one
analyte, gene module, cytokine hub, or molecular lesion. This is a **structural / evidence-
bar** claim about how evidence is scored, not a claim about any specific molecule.

**Corollary (the load-bearing part):** shared-*analyte* nulls bear on the sub-claim
"there is a shared PAIS-specific molecular signature", **not** on "there is a shared
persistent immune-state displacement". A cross-trigger analyte null must be filed against
the former and **must not be scored as disconfirming** the state-displacement frame.

## Evidence Summary

The claim reinterprets, rather than rests on, the head-to-head analyte nulls:
`paper:Galbraith2011` (no genes consistent across EBV/RRV/Q-fever PBMC), `paper:Patterson2024`
(cytokine-hub classifier *separates* long COVID from chronic Lyme), and `paper:Chowdhury2026`
(3-month plasma proteome distinguishes PCC from recovered by only 2 proteins). Under a
single-shared-molecule reading these count against h0001; under the degeneracy reading they
count only against the shared-molecule sub-claim and are **silent** on shared state
displacement. The strong shared-*pathway* prediction (`question:0001`) remains the most
discriminating *positive* test but is a bonus, not a precondition.

## Caveats

`structural_claim` / `background`: this disciplines the evidence bar; it is not itself
evidence that the displacement exists (that is `proposition:0038`) or that it is causal
(`proposition:0039`). Degeneracy is not unfalsifiable licence — it does not immunize h0001
against a *shared-pathway* null or against longitudinal/interventional disconfirmation; it
only blocks the specific inference "no shared analyte ⇒ no shared state".

# Evidence Line: Crotty2026 durable-priming memory review supports the imprinting-gate durability premise

## What this line shows

`paper:Crotty2026` (2026 immunological-memory review) supplies the durability premise `proposition:0045` depends on: the pertussis wP-vs-aP example shows infant priming fixes CD4 T-helper phenotype (T_H1 vs T_H2/T_H17) for decades despite repeated boosters — a human demonstration that early priming sets a durable, correction-resistant immune set point — and it establishes that tissue-resident memory requires local antigen encounter [@Crotty2026]. As a `background_constraint`, it makes the claim's premise (that seasonal-coronavirus imprinting can durably shape later SARS-CoV-2 responses) biologically credible.

## Why it is independent

This line contributes an analogical, mechanism-general durability argument from vaccine immunology, not any PAIS serological data; it is independent of `evidence-line:0095` (Mak2025), which supplies the PAIS-specific antibody pattern. The two are complementary — premise (Crotty2026) vs. instance (Mak2025) — with no shared source.

## Caveats / scope

`background_constraint`, weak. Crotty2026 is vaccine-centric and explicitly does *not* study how PAIS itself alters memory; its imprinting relevance to PAIS is analogical, not measured. It establishes that decades-long antigen-free set points are biologically real, but says nothing directly about whether OC43/HKU1 imprinting gates SARS-CoV-2 clearance — that link remains supplied only by Mak2025's inferential serology.

## Measurement Model

This line's support is analogical: the durable-set-point evidence is measured in a *different* antigen system (pertussis wP/aP CD4 phenotype), and is transferred to the seasonal-coronavirus → SARS-CoV-2 case by mechanistic analogy rather than direct measurement. The proxy relation is therefore cross-antigen generalization of a priming-durability principle; it constrains plausibility but cannot quantify the imprinting effect on SARS-CoV-2 clearance, which requires antigen-specific pre-infection repertoire data.

# Evidence Line: Peluso2026 (outSMART-LC) — null anti-RBD monoclonal in long COVID

## What this line shows

outSMART-LC (n=36; 2:1 AER002:placebo) tested a *different* clearance modality — a single 1,200 mg IV
infusion of the long-acting anti-RBD neutralizing monoclonal AER002 — in WHO-defined long COVID (median
740 days since infection, highly symptomatic, 86% PEM). It was **null** on the primary PROMIS-29 PHSS at
Day 90 and on all pre-specified secondaries. Because this is a neutralizing antibody rather than an Mpro
inhibitor, it adds a **mechanistically independent** brick to the same uninterpretable-null pattern,
weakly disputing `proposition:0020`.

## Why it is independent

`independence: independent` — UCSF LIINC cohort, distinct from STOP-PASC and PAX-LC, and a distinct drug
class (anti-RBD mAb vs protease inhibitor). This matters: the established-disease null now spans two
unrelated clearance strategies.

## Caveats / scope

**Weak**, and again no demonstrated target-engagement: **no plasma antigen-clearance assay was run**, and
baseline tissue antigen was scarce (gut-biopsy RNA in only 1/17), so antigen-positive enrichment was
infeasible. Further bounded by: very small n=36; single infusion (may not reach tissue reservoirs); a
hypothesis-generating exploratory signal (lower baseline anti-Spike + higher AER002 exposure → more
self-reported improvement; PET-suggested lower tissue T-cell activation) that did *not* reach the
group-level endpoint; preprint; long COVID only. Per `discussion:0003`, this null **does not refute**
`hypothesis:0002`; the exploratory exposure-response signal is, if anything, a faint hint that the
reversible-target reading is not dead — only untested by an adequate vehicle.

# Evidence Line: Peripheral-extraction physiology weakly supports h0006 P2

## What this line shows

Joseph2023 synthesizes invasive CPET evidence in ME/CFS and PASC showing preload failure and impaired
peripheral O2 extraction during exertion. The high-flow/extraction-failure physiology indicates that
oxygenated blood can return to the venous circulation without being extracted by exercising tissue,
consistent with dysautonomic shunting, microvascular dysfunction, endothelial dysfunction, or
mitochondrial myopathy.

This weakly supports h0006 P2 because it places a vascular/delivery/extraction abnormality in the
provoked exercise pathway, upstream or alongside the muscle bioenergetic deficit.

## Caveats / scope

The line is `proxy_support`, not a direct causal test. Joseph2023 is a narrative review, many underlying
iCPET studies are referral-enriched, and iCPET extraction failure cannot by itself distinguish
microvascular shunting from intrinsic mitochondrial utilization failure. It supports the plausibility of
the P2 upstream-delivery leg, not the full ischemic cause.
